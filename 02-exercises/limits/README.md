# Files for exercise 3

Files that [Exercise 3](../05-limits.md) downloads into the project folder. You
do not need to open them here; the agent downloads them for you.

| File | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Level 1: the rules of the project, written for the model. Never change `data/raw`, fix data with a script |
| [`leaves.csv`](leaves.csv) | Twelve made-up leaf measurements, with one typo (`245` instead of `24.5`). Goes into `data/raw` |
| [`opencode.json`](opencode.json) | Level 2: permissions that the opencode app enforces. Blocks edits in `data/raw`, asks before shell commands and downloads. Downloaded as `setup/permissions.json`; in part C the participant renames it and moves it into the project folder |
