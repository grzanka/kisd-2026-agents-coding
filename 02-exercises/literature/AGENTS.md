# Rules for this project

We do literature research: where does the word "regression" come from, and
can we find and reproduce the original data?

## How to work with me

- Before each tool call, say in one sentence what you will do and why.
- Keep apart what you **read in a source** and what you **know from memory**.
  Mark everything from memory with "(from memory, not checked)".
- For every claim from a source, give the source and the page or section.
  Quote at most one short sentence; otherwise write in your own words.
- Never invent a reference, a DOI or a page number. If you are not sure that
  a reference exists, say so, and check it.

## Sources

- Save downloaded papers into sources/, with a short file name
  (author-year-word.pdf). Never change files in sources/.
- Keep sources/SOURCES.md up to date: one line per source, with authors,
  year, title, where it was published, URL or DOI, the date you accessed it,
  and whether the full text is free or paywalled.
- Do not try to get around a paywall: no shadow libraries, no copies of
  unclear origin. If a source is paywalled, tell me, and I ask my library.
- The folder ../kisd-library holds papers that I have, as PDF files. You may
  read them, never change them.

## Code and data

- Run Python only with .venv\Scripts\python.exe (on Linux and macOS:
  .venv/bin/python). Install packages only into .venv.
- Write notes into notes/, scripts into scripts/, data that you transcribe or
  digitize into data/, and reports and plots into results/.
- Never open an image or plot window; save images as PNG files.
- Do not read whole PDF files into the conversation. Extract the pages you
  need, or render one page as an image and look at it.
