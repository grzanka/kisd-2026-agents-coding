# Files for exercise 7

Files that [Exercise 7](../09-literature.md) downloads into the project folder.
You do not need to open them here; the agent downloads them for you.

| File | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | The rules of the project: memory versus sources, a page for every claim, never invent a reference, a list of sources, no getting around paywalls, read `../kisd-library` but never change it |
| [`opencode.json`](opencode.json) | The permissions: ask before going outside the project, except `kisd-library`, which the agent may read but not change |

The papers are not in this repository. You save them yourself into
`kisd-library`, in your browser: Galton (1886) from
[galton.org](https://galton.org/essays/1880-1889/galton-1886-jaigi-regression-stature.pdf)
(public domain), and the author's copy of Hanley (2004) from
[his website](https://jhanley.biostat.mcgill.ca/Reprints/Hanley_Article_Galton_Data.pdf).
