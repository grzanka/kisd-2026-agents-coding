# Files for exercise 2

Files that [Exercise 2](../04-meteo.md) downloads into the project folder. You
do not need to open them here; the agent downloads them for you.

| File | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | The rules of the project in learning mode: the agent explains, asks check questions, and keeps the raw data untouched |

The weather data itself is not in this repository. It is a ZIP file attached to
the release
[GIG Katowice weather data 2006-2026](https://github.com/grzanka/kisd-2026-agents-coding/releases/tag/data-gig-meteo-2006-2026):
an unchanged copy of the archive at <https://meteo.gig.eu/archiwum/>, licence
CC BY 4.0.
