# Rules for this project

We measure things in photos. The photos are in photos/.

- Before each tool call, say in one sentence what you will do and why.
- Work only inside this project folder. Never search, read or write files
  outside it. If a file is missing, ask me where it is.
- Run Python only with .venv\Scripts\python.exe (on Linux and macOS:
  .venv/bin/python). Install packages only into .venv.
- Write scripts into scripts/, and results (numbers, marked images) into
  results/.
- Never change files in photos/.
- Never open an image window; save images as files.
- For every measurement: give the value in pixels first, say which reference
  of known size you used to convert it, give a range and not only one number,
  and draw what you measured on a copy of the photo.
