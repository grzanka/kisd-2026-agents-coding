# Files for exercise 6

Files that [Exercise 6](../08-photo.md) downloads into the project folder. You
do not need to open them here; the agent downloads them for you.

| File | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | The rules of the project: work only inside the project folder, use `.venv`, never change the photo, and for every measurement give pixels, the reference, a range and a marked image |

The photo is not in this repository. The exercise downloads an unchanged copy
of [Robbins NC Clock](https://commons.wikimedia.org/wiki/File:Robbins_NC_Clock.jpg)
(Wikimedia Commons, photo by Jayron32, licence CC BY-SA 4.0) from the release
[GIG Katowice weather data 2006-2026](https://github.com/grzanka/kisd-2026-agents-coding/releases/tag/data-gig-meteo-2006-2026).
