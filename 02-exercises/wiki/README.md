# Files for exercises 8 to 11

Files that [Exercise 8](../10-wiki.md) downloads into the project folder
`kisd-wiki`. Exercises 9 to 11 continue in the same folder. You do not need to
open them here; the agent downloads them for you.

| File | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | The schema of the wiki: `raw/` is never changed, `wiki/` is the agent's, every page ends with its sources, and the three operations ingest, query and lint |

The sources are not in this repository. The agent downloads them: Galton
(1886) from [galton.org](https://galton.org) (public domain), the arXiv paper
[1508.02942](https://arxiv.org/abs/1508.02942), and two Wikipedia articles as
raw text (CC BY-SA).
