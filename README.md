# kisd-2026-agents-coding

Lecture materials on **agentic coding for data analysis**, using
[opencode](https://opencode.ai) and [llmlab at Cyfronet](https://llmlab.plgrid.pl)
(PLGrid Forge). The course is for PhD students of the KISD doctoral school.

**Where to start:** read the five pages in `docs` in order (they set up opencode
on your computer), then do the exercises in order.

## Contents

1. [`docs/`](docs/README.md) — background and setup, in this order:
   1. [Chatbot or agent](docs/01-chatbot-or-agent.md)
   2. [Install the opencode app](docs/02-install-opencode.md)
   3. [Get access to llmlab](docs/03-get-llmlab-access.md)
   4. [Connect opencode to llmlab](docs/04-connect-opencode-to-llmlab.md)
   5. [First steps in opencode](docs/05-first-steps.md)
2. [`exercises/`](exercises/README.md) — hands-on tasks with copy-paste prompts:
   1. [Your first agent session — measuring *g* with a pendulum](exercises/01-pendulum.md)
3. Later, optional: [opencode and Claude Code](docs/06-opencode-vs-claude-code.md)

Supporting folder: [`config/`](config/README.md) — the opencode settings file
that page 4 downloads ([opencode.json](config/opencode.json)).
