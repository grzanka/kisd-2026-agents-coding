# kisd-2026-agents-coding

Lecture materials on **agentic coding for data analysis**, using
[opencode](https://opencode.ai) and [llmlab at Cyfronet](https://llmlab.plgrid.pl)
(PLGrid Forge). The course is for PhD students of the KISD doctoral school.

**Where to start:** set up opencode with the two pages in `docs`, then do the
exercises in order.

## Contents

- [`docs/`](docs/README.md) — background and setup
  - [What is opencode](docs/opencode.md)
  - [PLGrid Forge (llmlab) — using it from opencode](docs/plgrid-forge.md)
- [`exercises/`](exercises/README.md) — hands-on tasks with copy-paste prompts
  - [Exercise 1: Your first agent session — measuring *g* with a pendulum](exercises/01-pendulum.md)
