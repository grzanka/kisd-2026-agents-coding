# Exercises

Hands-on tasks for the lectures. In each one you give an AI agent (opencode)
short prompts and watch it read, write and run files on your computer. All
prompts are ready to copy and paste. You do not need to know Python.

| # | Exercise | What you learn | Time |
|---|---|---|---|
| 1 | [Your first agent session — measuring *g* with a pendulum](01-pendulum.md) | How an agent differs from a chat: tool calls, the agentic loop, creating and editing files | 30–40 min |

## Before you start

Go through the [docs](../docs/README.md) in order. You need:

- the opencode app installed ([2. Install the opencode app](../docs/02-install-opencode.md));
- an llmlab API key ([3. Get access to llmlab](../docs/03-get-llmlab-access.md));
- opencode connected to llmlab ([4. Connect opencode to llmlab](../docs/04-connect-opencode-to-llmlab.md)).

Do the exercises in order. Each one runs in its own new folder.
